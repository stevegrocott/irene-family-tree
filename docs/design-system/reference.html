Irene Family Tree
Design System v1
Reference implementation

A quieter graph, a warmer record

The viewer's problem was never decoration — it was that nothing on screen told you where a generation began, and every node shouted at the same volume. This system kills the glass, bands the generations, ties node detail to zoom, and lets colour mean exactly one thing at a time. Person names are set in a serif; every date, id and diff in mono. That contrast is the identity.

Overview
Bands, not glows

One tinted band per generation rank, a hairline between, a sticky gutter label at the left. Generation 0 takes the brass tint. Reuse the y-levels generationsFromLayout already clusters.

Detail follows zoom

Below 0.45 a node is a coloured dot; to 0.85 it is name plus year; above that it is the full card. At overview zoom you read shape, not text you can't read anyway.

Lineage focus

Hover or select a person and everything off their direct line drops to 22 % opacity. One BFS over the loaded graph — and the single largest legibility win available.

Inputs Birth place Ballarat East, VIC 18a4 Year must be four digits.
Do Band every generation and label the gutter. Switch node detail on zoom, not on data. Dim everything off the hovered person's line. Set names in the serif, facts in the mono. Give every tap target 44 px on mobile.
Don't Translucent glass fills or backdrop blur on nodes and panels. Glow shadows, or scale transforms on hover. Colour used decoratively — sex is a 3 px tick, not a glow. 16 px radii, or hard-coded hex outside tokens.css. Sliders for hop depth, or a graph with no minimap.
